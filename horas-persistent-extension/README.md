# Horas siempre disponible

Esta extensión mantiene abierta una pestaña normal con:

`http://localhost:8085/` (Broadway GTK3 nativo)

Funciona de lunes a viernes. Comprueba la pestaña al iniciar Chrome, cuando se
cierra o cambia una pestaña y, como respaldo, una vez por minuto. Los fines de
semana no abre ni cierra la página. Al pulsar el icono de la extensión, abre o
enfoca Horas cualquier día.

## Instalación en Google Chrome

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador**.
3. Pulsa **Cargar descomprimida**.
4. Selecciona la carpeta:
   `/home/user/monoliths-llm/horas-persistent-extension`
5. En la tarjeta de la extensión, pulsa **Recargar**.

La pestaña abrirá la versión publicada y no robará el foco mientras trabajas.
